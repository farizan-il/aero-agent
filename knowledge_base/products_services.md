# Knowledge Base: Produk & Layanan TechNusantara

## 1. NusantaAgent (AI Agent Enterprise Platform)
Platform orkestrasi agent otonom untuk otomatisasi proses bisnis:
- **Fitur Utama**:
  - Dukungan Multi-Agent (kolaborasi antar agent khusus: sales, support, data analyst).
  - Integrasi RAG hybrid (Vector search + Keyword search) dengan enkripsi data end-to-end.
  - Konektor siap pakai ke SAP, Salesforce, PostgreSQL, WhatsApp Business, dan Slack.
- **Harga**:
  - Basic: Rp 3.500.000 / bulan (hingga 5 agent, 50.000 interaksi).
  - Pro: Rp 9.500.000 / bulan (hingga 25 agent, 250.000 interaksi, custom fine-tuning).
  - Enterprise: Custom pricing (unlimited agent, on-premise deployment tersedia).

## 2. NusantaraVision (Computer Vision AI)
Solusi inspeksi visual otomatis berbasis kamera industri untuk manufaktur dan keamanan:
- Deteksi cacat produksi secara real-time dengan akurasi 99.4%.
- Pengenalan pelat nomor kendaraan otomatis (ANPR) dan penghitungan kerumunan.
- Integrasi ke sistem SCADA dan PLC industri.

## 3. DataBridge Cloud (Data Pipeline & Analytics)
Infrastruktur data lakehouse modern untuk aggregasi dan analisis data:
- Sinkronisasi data real-time dengan latency di bawah 2 detik.
- Dashboard visualisasi terintegrasi dan pelaporan otomatis terjadwal.
